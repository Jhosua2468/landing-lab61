Sistema Web de Planificación de Viajes Económicos

Proyecto Final - Asignatura: Trabajando en la Nube (COM610)

Descripción del Proyecto

Plataforma diseñada con arquitectura cliente-servidor para optimizar la planificación de rutas y presupuestos turísticos.

Arquitectura Cloud

  • Frontend: Vue.js (Alojado en S3 + CloudFront)
  • Backend: NestJS (Instancia EC2)
  • Base de Datos: Amazon RDS (MySQL)
